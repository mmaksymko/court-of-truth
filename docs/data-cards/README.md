# Картки корпусів локальних детекторів

Ці картки описують фактичний стан чотирьох CSV-файлів, використаних для
навчання локальних детекторів. Вони не надають нового дозволу на використання
або повторне поширення текстів. Якщо в картці зазначено, що ліцензійну підставу
не встановлено, повний CSV слід вважати локальним дослідницьким артефактом, а
не складником відкритого пакета.

Спільні правила публікації:

- наводити агрегати, контрольні суми, ідентифікатори та мінімально потрібні
  фрагменти;
- не включати повні сторонні публікації до публічного архіву без окремої
  перевірки умов використання;
- перед оприлюдненням прикладу перевіряти контактні й інші зайві персональні
  відомості;
- не тлумачити операційну мітку як юридичне або універсальне визначення явища.

Картки фіксують стан файлів із контрольними сумами, наведеними в кожному
документі. Після зміни CSV відповідну картку потрібно переглянути повторно.

Рядкові реєстри аудиту зберігаються поза навчальними CSV у
`report/shortened edition/version 7/qa/data`. Реєстр `clickbait` містить URL і
хеші без заголовків, а реєстр контактних сигналів — лише категорії та рішення
про непублікацію без самих контактних значень. Ці файли не є додатковою
ліцензією і не змінюють модельні дані.
